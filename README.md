## 🚀 Setup & Development Instructions

### Option A: Direct Static Run (Zero Install)
Double click `index.html` in any modern browser (Chrome, Edge, Safari, Firefox). All styling (Tailwind CDN) and icons load automatically.

### Option B: Local Development with Node / Vite
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production hosting
npm run build
```
